# D-Safe PowerPoint Generator V36.4.61

Panel Home dipindahkan ke tengah tepi atas dan tetap melayang dengan animasi turun. Lapisan biru transparan tipis membentang sepanjang tepi atas layar; lapisan ini tidak menangkap klik dan teks di bawah tetap terbaca. Tombol (+) dan kembali mempertahankan posisi V36.4.60. Transisi turun ke Beranda tetap tersedia saat Home diklik.

Windows CMD:
    cd /d "%USERPROFILE%\Downloads\dsafe-ppt-generator-v36.4.61"
    python -m pip install -r requirements.txt
    python -m streamlit run app.py
