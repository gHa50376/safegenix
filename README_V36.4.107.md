# D-Safe V36.4.107 — Filter waktu arsip kegiatan

**Pengaturan → Cadangan Data → Filter waktu** menyediakan Semua kegiatan, Minggu (Senin–Minggu), Bulan, Tahun, dan Rentang tanggal. Jumlah kegiatan yang akan dipindahkan dan yang tetap berada di aplikasi ditampilkan sebelum unduhan.

**Reset dan Cadangkan** mengunduh ZIP sesuai filter. Setelah pengguna memastikan berkas tersimpan dan mengonfirmasi, hanya sesi Buku Kerja pada periode itu yang dihapus dari aplikasi. Di luar periode, sesi tetap ada. Master stasiun, pengguna/NIPP, petugas, dan daftar kegiatan selalu dipertahankan. Untuk **Semua kegiatan**, cadangan lama dan draf tersimpan ikut dimasukkan ke ZIP lalu dibersihkan dari aplikasi seperti V36.4.106. Untuk filter periode, cadangan lama dan draf tetap ada agar data di luar periode tidak ikut terhapus.

**Pulihkan Cadangan** membuka pemilih ZIP/JSON. ZIP periode menambahkan kegiatan yang belum ada berdasarkan ID; pengulangan pemulihan tidak menggandakan kegiatan dan tidak mengganti data di luar periode atau master yang sedang aktif. ZIP seluruh kegiatan dan JSON versi lama memakai pemulihan penuh dengan konfirmasi seperti sebelumnya.
