# D-Safe PowerPoint Generator V36.4.19

Perubahan versi ini berfokus pada **Riwayat Kegiatan Buku Kerja**.

- Riwayat Kegiatan sekarang menggunakan format tabel yang sama dengan Cetak/PDF.
- Header 3 baris: header utama, YA/TIDAK, dan nomor 1–6.
- Semua input ditampilkan dalam satu tabel, tanpa batas 4 kegiatan.
- Urutan mengikuti urutan input.
- Nomor kembali ke 1 untuk setiap bulan.
- Foto dokumentasi hanya di kolom KETERANGAN.
- TTD berada di kolom RENCANA KERJA di bawah seluruh isi kegiatan.
- CCTV hanya menampilkan Petugas, Hasil Pengawasan, dan Tindak Lanjut.
- Edit/Hapus tetap tersedia melalui pemilih aksi di atas tabel.

Fungsi input, penyimpanan, Edit data, foto, Safety Talk, CCTV, dan TTD tidak diubah.
