# V36.4.28

Baseline: V36.4.27.

Perubahan terbatas pada sub kegiatan **Satu Hari Satu Pasal**:
- Dinas Pagi, Dinas Siang, dan Dinas Malam sekarang dipilih dari Master Data Petugas.
- Pilihan menampilkan `Nama / NIPP` sesuai kapitalisasi Master Data.
- Nilai `Nama / NIPP` diteruskan ke struktur note lama agar mapping D-Safe yang sudah ada tetap kompatibel.
- Edit data lama tetap mencoba mencocokkan Nama, NIPP, atau `Nama / NIPP` ke Master Data.
- Tidak mengubah Safety Talk, CCTV, TTD, Riwayat, Cetak/PDF, template PPT, atau sub kegiatan lain.
