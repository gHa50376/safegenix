# D-Safe V36.4.106 — Arsip kegiatan yang meringankan aplikasi

Di **Pengaturan → Cadangan Data**, **Reset dan Cadangkan** mengunduh satu ZIP berisi `buku_kerja.json`, salinan cadangan lama yang masih ada di folder aplikasi, serta draf tersimpan bila ada. Setelah memastikan ZIP sudah tersimpan di perangkat, tekan **Sudah tersimpan, reset kegiatan**. Aplikasi mengosongkan seluruh sesi Buku Kerja dan menghapus salinan cadangan serta draf yang sudah masuk ZIP. Nama stasiun, pengguna/NIPP, master petugas, dan daftar kegiatan tetap ada.

Browser tidak dapat memastikan lokasi atau keberhasilan penyimpanan unduhan. Karena itu, kegiatan belum dihapus ketika unduhan baru dimulai. Bila dialog dibatalkan atau data berubah sebelum konfirmasi, kegiatan tetap tersimpan; unduh ulang arsip terbaru.

**Pulihkan Cadangan** dapat membaca ZIP baru dan JSON dari versi sebelumnya. Pemulihan ZIP mengembalikan Buku Kerja beserta drafnya. Salinan kondisi sebelum pemulihan disimpan sementara di aplikasi dan akan dimasukkan ke ZIP serta dihapus pada reset berikutnya.
