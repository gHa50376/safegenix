# D-Safe V36.4.73

Perubahan tampilan dan Pengaturan:

- Petunjuk mengambang berlatar putih pada tombol navigasi dan formulir dihilangkan. Aksi bergambar di riwayat tetap memiliki nama aksesibilitas tanpa tooltip. Judul preview Buku Kerja, label periode Safety Talk Mingguan, nama pilihan pada layar HP, dan label panjang pada Dashboard diberi ruang agar terbaca.
- Pengaturan menampilkan Nama Stasiun dan tombol Edit; tombol Simpan hanya muncul saat editor stasiun dibuka.
- Menu baru Nama Pengguna dan NIPP menyimpan kedua nilai sebagai identitas pengguna tersendiri.
- Edit Petugas membuka form Tambah Petugas di atas daftar petugas tersimpan. Petugas tersimpan tetap dapat diedit dan dihapus.
- Edit Kegiatan menampilkan tiga pilihan dalam urutan Kegiatan Lainnya, Program Keselamatan Kerja, dan D-Safe & Safety Talk. Form Tambah Kegiatan tampil di atas daftar kegiatan grup aktif. Kegiatan bawaan tetap ada dan tidak dapat dihapus; kegiatan baru dapat diedit atau dihapus.
- Hanya satu panel Pengaturan aktif pada satu waktu; berpindah tombol menutup panel yang sebelumnya terbuka.

Pengujian browser pada lebar 1365 px dan 390 px meliputi perpindahan menu, simpan stasiun dan pengguna, tambah/edit/hapus petugas dan kegiatan tambahan, teks pilihan dan preview, serta regresi unggah foto dan tanda tangan Buku Kerja. Data contoh pengujian tidak dimasukkan dalam paket.
