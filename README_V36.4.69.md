# D-Safe V36.4.69 — Dashboard Kinerja

Dashboard Kinerja sekarang menyediakan filter Minggu, Bulan, Tahun. Minggu dimulai Senin dan berakhir Minggu; pemilihan tanggal apa pun menampilkan minggu yang menaunginya. Tanggal acuan menggunakan WIB (UTC+7), sesuai penggunaan Stasiun Garut.

Periode yang dipilih mengubah seluruh ringkasan: total pelaksanaan, jenis kegiatan aktif, jumlah petugas unik, partisipasi, grafik kegiatan paling sering, sebaran pelaksanaan, daftar petugas, dan rincian semua kegiatan per kelompok. Kegiatan kosong tetap bisa dilihat dalam rincian. Entri Pengawasan CCTV lama yang kurang satu petugas atau foto diberi penanda untuk diperiksa di Buku Kerja.

Tampilan menyesuaikan desktop dan HP; tiga pilihan periode berada pada satu baris dan tidak memerlukan geser ke samping. Pengujian browser: minggu lintas bulan, minggu kosong, September/Oktober 2026, tahun 2025/2026, serta tampilan HP untuk ketiga filter. Paket ini tidak menyertakan data uji.
