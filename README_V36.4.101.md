# D-Safe V36.4.101 — Dashboard Kepala Stasiun

- Judul “Capaian Target” diganti “Program Keselamatan Kepala Stasiun”.
- Target mingguan pada filter Bulan/Tahun dihitung empat kesempatan per bulan dan tetap membedakan minggu Senin–Minggu. Kegiatan berulang dalam minggu yang sama tidak menambah capaian.
- Kolom “Kegiatan paling sering” dan “Sebaran pelaksanaan” dihapus.
- Rekap kegiatan tanpa target tampil langsung tanpa kelompok. Kegiatan dari kelompok Kegiatan Lainnya tidak ditampilkan, kecuali Dinas PPKA. Angka ringkasan dan partisipasi mengikuti kegiatan yang terlihat.

Data Buku Kerja, riwayat, dan hasil PDF/PPT tidak dihapus atau diubah oleh penyaringan Dashboard ini.
