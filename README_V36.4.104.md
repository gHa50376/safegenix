# D-Safe V36.4.104 — Cadangan Data

Di Pengaturan terdapat bagian **Cadangan Data** yang tertutup secara bawaan. **Unduh Cadangan** menyimpan stasiun, pengguna, petugas, kegiatan, riwayat, foto, dan tanda tangan dalam satu JSON. **Pulihkan Cadangan** memvalidasi berkas, meminta konfirmasi, serta membuat salinan data aktif di folder `data` sebelum menggantinya.

Pemulihan hanya menerima berkas dari tombol Unduh Cadangan versi ini. Fungsi Buku Kerja, dashboard, PDF, dan PPT mengikuti V36.4.103.
