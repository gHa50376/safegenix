# D-Safe V36.4.103 — Tanggal WIB dan validasi foto Langsir

- Tanggal bawaan input Buku Kerja, filter Buku Kerja, periode D-Safe, dan periode Safety Talk mengikuti hari di WIB (UTC+7), termasuk saat server berjalan dalam zona waktu UTC.
- Pengawasan Langsir yang baru tidak tersimpan sampai satu foto diunggah. Saat mengedit catatan dengan foto lama, foto tersebut tetap dapat dipertahankan.

Dashboard dan fungsi lain mengikuti V36.4.102. Pemeriksaan browser pada data uji memastikan foto Langsir masuk ke PPT Safety Talk serta nama PDF/PPT mengikuti tanggal WIB.
