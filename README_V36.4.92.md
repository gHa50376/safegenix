# D-Safe V36.4.92

- Khusus tiga pilihan petugas pada Satu Hari Satu Pasal di layar HP, teks kosong tampil utuh sebagai “Pilih Petugas” dalam satu baris dengan tombol lebih ringkas.
- Lebar, panah, dan ruang dalam tombol dirapikan tanpa mengubah pilihan petugas, widget, urutan dinas/foto, penyimpanan, dan keluaran laporan.
- Bagian lain tetap mengikuti V36.4.91.
