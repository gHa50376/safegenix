# D-Safe V36.4.91

- Memperbaiki pembacaan catatan Pengawasan CCTV ketika Hasil Pengawasan atau Tindak Lanjut kosong. Label kolom berikutnya tidak lagi masuk sebagai isi kolom sebelumnya.
- Perbaikan berlaku pada data Buku Kerja yang telah tersimpan, pratinjau, PPT D-Safe, dan PPT Safety Talk Mingguan tanpa mengubah data yang tersimpan.
- Semua bagian lain tetap mengikuti V36.4.90.
