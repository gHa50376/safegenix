# D-Safe PowerPoint Generator V36.4.60

Home di seluruh halaman tampil dalam panel kaca transparan yang melayang di tepi kanan atas. Panel turun saat muncul dan merespons hover/tekan. Saat Home diklik, panel memberi transisi turun singkat bersama masuknya Beranda. Tombol (+) Buku Kerja berada tepat di bawah panel; tombol kembali pada form tetap dapat diklik di sebelahnya.

Warna tombol Pengaturan dan gradasi putih-oranye untuk Download Buku Kerja/Generate PPT tetap mengikuti V36.4.59. Alur input, riwayat, PDF, PPT, serta data kegiatan tidak berubah.

Windows CMD:
    cd /d "%USERPROFILE%\Downloads\dsafe-ppt-generator-v36.4.60"
    python -m pip install -r requirements.txt
    python -m streamlit run app.py
