# D-Safe V36.4.105 — Reset dan Cadangkan

Di Pengaturan → Cadangan Data, **Reset dan Cadangkan** membuat salinan JSON lengkap, mengunduhnya, lalu mengosongkan riwayat kegiatan. Stasiun, pengguna, petugas, dan daftar kegiatan tetap tersimpan. Salinan cadangan juga disimpan di folder `data` aplikasi sebelum reset; **Unduh Ulang Cadangan** tersedia bila unduhan awal tidak ditemukan.

**Pulihkan Cadangan** langsung membuka pemilih berkas perangkat. Setelah berkas JSON diperiksa, aplikasi meminta konfirmasi sebelum mengganti data dan menyimpan salinan data aktif sebelumnya. Berkas cadangan V36.4.104 tetap dapat dipulihkan.

Lokasi penyimpanan unduhan ditentukan browser dan pengaturan perangkat. Pada sebagian HP, pengguna dapat memilih penyimpanan internal atau eksternal melalui dialog unduh atau aplikasi berkas; browser tidak selalu menampilkan pemilih folder.
