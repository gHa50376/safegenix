# D-Safe V36.4.100 — Keterangan capaian Dashboard

Dashboard menjelaskan satuan capaian target per petugas dan periode. Angka pada batang menunjukkan jumlah target yang terpenuhi dibanding jumlah kesempatan target. Legenda warna kini menyebut batas persentasenya.

Saat filter Minggu dipilih, batang dua kegiatan bertarget bulanan diberi keterangan sebagai kontribusi minggu itu. Capaian bulan tetap dilihat melalui filter Bulan atau Tahun. Cara hitung, data, dan fungsi halaman lain mengikuti V36.4.99.
