# D-Safe PowerPoint Generator V36.4.57

Kalender pada seluruh kolom tanggal tampil lebih modern: bidang tanggal biru-putih, pop-up membulat dengan bayangan lembut, sel hari yang rapi, serta tanggal terpilih dan navigasi bulan yang lebih jelas. Lebar pop-up dibatasi agar muat di layar HP. Warna utama Streamlit disamakan dengan biru aplikasi agar pilihan tanggal tetap biru pada variasi versi kalender.

Logika tanggal, Buku Kerja, PDF, dan PPT tidak berubah.

Windows CMD:
    cd /d "%USERPROFILE%\Downloads\dsafe-ppt-generator-v36.4.57"
    python -m pip install -r requirements.txt
    python -m streamlit run app.py
