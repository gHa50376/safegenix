# D-Safe PowerPoint Generator V36.4.17

Perubahan versi ini hanya pada output Cetak / PDF Buku Kerja:

- Header tabel menjadi 3 baris seperti format contoh: header utama, subheader YA/TIDAK, lalu nomor kolom 1–6.
- Urutan kegiatan mengikuti urutan input (`createdAt`), paling awal dicetak paling atas.
- Nomor kegiatan reset ke 1 setiap pergantian bulan berdasarkan tanggal kegiatan.
- Maksimal 4 kegiatan per lembar tetap dipertahankan.
- Perubahan tidak menyentuh input, penyimpanan, Edit, foto, Safety Talk, CCTV, atau TTD.
