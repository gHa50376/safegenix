# D-Safe V36.4.108 — Nama arsip Buku Kerja

Nama ZIP dari **Reset dan Cadangkan** kini mengikuti `Buku Kerja_Nama Stasiun_Tgl awal s.d Tgl akhir.zip`. Filter Minggu, Bulan, Tahun, atau Rentang tanggal memakai batas tanggal filter yang dipilih. Filter **Semua kegiatan** memakai tanggal kegiatan paling awal dan paling akhir yang tersimpan; bila hanya cadangan/draf lama yang diarsipkan tanpa sesi bertanggal, nama menggunakan `Semua Kegiatan`.

Isi arsip, proses reset, pemulihan, dan data master tetap mengikuti V36.4.107.
